# 자양한강도서관 예약 도서 라벨 인쇄 시스템

도서관 예약 명단(엑셀/CSV)에서 **예약자 이름**을 추출해, Epson LW-K600 라벨 프린터용 **30mm × 12mm** 라벨을 일괄 인쇄하는 웹 앱입니다.

## 기능

- `.xlsx`, `.xls`, `.csv` 파일 업로드 (드래그앤드롭 지원)
- **예약자** 열 자동 감지 및 이름 추출
- 한글/영문 이름 검증, 가나다순 정렬
- 동명이인·필터링 통계 표시
- 이름 검색, 개별 삭제, 글자 크기 조절
- 라벨 1장 = 1페이지 일괄 인쇄

## 인쇄 방법 (권장)

1. **PDF로 일괄 인쇄** 버튼 클릭 — 30×12mm 페이지가 고정된 PDF 생성
2. 프린터 설정:
   - 테이프 길이: **자동(Auto)** — 드라이버에서 30mm 고정하지 마세요
   - 배율: **100%** (페이지에 맞춤 끄기)
   - 여백: 없음
3. 문제 시 **PDF 저장** 후 Adobe Reader 등에서 인쇄하거나 **브라우저 직접 인쇄** 사용

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 으로 접속합니다.

## 빌드

```bash
npm run build
npm run preview
```

## 인쇄 설정

인쇄 전 아래 설정을 확인하세요.

| 항목 | 설정 |
|------|------|
| 프린터 | Epson LW-K600 |
| 용지 방향 | 가로 (Landscape) |
| 여백 | 없음 |
| 배경 그래픽 | 해제 |

## 엑셀 파일 형식

- 첫 번째 시트 사용
- **예약자** 헤더가 포함된 열 필요
- 한글 이름 2–4자, 영문 이름 2–30자만 추출

## 기술 스택

- React 19, TypeScript, Vite 8
- Tailwind CSS 4
- SheetJS (`xlsx`)
